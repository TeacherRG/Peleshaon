# Пеле Шаон Луах (Pele Shaon Luach)

Приложение для Android и Wear OS: еврейский календарь, времена дня, Шабат, будильники и напоминания. Работает полностью без интернета.

> Название продукта: **Пеле Шаон Луах**  
> Латинское написание: **Pele Shaon Luach**  
> Android application ID: `app.niflaot.peleshaon`

## Текущий статус

Версия **1.0.0-beta4** готовится к бета-тестированию в Google Play.

- Телефон: `versionCode=7`, `targetSdk=36`.
- Wear OS: `versionCode=100007`, `targetSdk=35`.

Выпуск в Google Play описан в [PLAY_RELEASE.md](PLAY_RELEASE.md): ключ загрузки, секреты GitHub, Play Console, Data safety, декларации разрешений и дорожки тестирования. Тексты страницы магазина и «Что нового» на 5 языках лежат в [`fastlane/metadata/android/`](fastlane/metadata/android/).

## Возможности

- **Еврейский календарь.** Месяц сеткой с гражданскими датами. Показывает праздники, посты, Рош Ходеш, Хануку, Омер, недельную главу и даты Хабада. Порядок диаспоры или Израиля выбирается по городу.
- **Мои напоминания в календаре.**
  - Можно добавлять, изменять и удалять свои напоминания.
  - Повтор: по гражданской дате (день, неделя с выбором дней, месяц, год) или по еврейской дате (каждый месяц, каждый год — йорцайты, дни рождения).
  - Можно задать интервал и дату окончания.
  - Уведомление приходит за выбранное время. В Шабат и Йом Тов оно откладывается до исхода.
  - **Импорт** из Google Календаря (ZIP-выгрузка или `.ics`) и из файлов `.vcs`.
  - **Экспорт** в стандартные форматы iCalendar `.ics` (RFC 5545) и vCalendar `.vcs`.
- **Времена дня (зманим).** Расчёт по методу Алтер Ребе, по литовскому или сефардскому обычаю. Циферблат с галахическими часами.
- **Шабат и праздники.** Зажигание свечей (свои минуты для города или выбранные вручную) и исход.
- **Будильники.**
  - Утренний будильник ко времени или до конца времени Шма.
  - Будильник учёбы Торы и свои будильники.
  - Все молчат от зажигания свечей до исхода Шабата и Йом Това.
- **Таймер «мясное → молочное»** на 6 часов.
- **Кидуш Левана:** напоминание, компас Луны и направление на Йерушалаим.
- Виджеты, ночной экран и заставка.
- **Wear OS:** отдельное приложение для часов с собственными настройками.
- **Языки:** русский, украинский, английский, немецкий, иврит.

## Компоненты

- `:app` — Android-приложение для телефона.
- `:wear` — приложение для Wear OS.
- `:core` — общая логика для телефона и часов: расчёт времён, еврейский календарь, правила будильников, напоминания, чтение и запись `.ics`/`.vcs`. Модуль на чистом Kotlin/JVM, тесты запускаются без Android.

## Сборка для разработки

Нужны Gradle 8.11.1+, JDK 17 и Android SDK 36. Откройте репозиторий в Android Studio и дождитесь синхронизации Gradle.

```bash
python3 scripts/check_integrity.py        # переводы, версии, обязательные проверки
gradle :core:test                         # тесты логики
gradle :app:assembleDebug :wear:assembleDebug
gradle :app:bundleRelease :wear:bundleRelease   # AAB для Google Play
```

Release-сборки подписываются ключом загрузки Google Play, только если он передан через переменные окружения или `~/.gradle/gradle.properties`. Иначе они остаются неподписанными. Подробнее — в [PLAY_RELEASE.md](PLAY_RELEASE.md).

Тестовые APK из GitHub Actions подписаны общим debug-ключом и предназначены только для проверки. Не используйте debug-ключ для публикации.

## Проверки

GitHub Actions выполняет:

- проверку целостности исходников и переводов;
- тесты `:core`;
- сборку debug/QA APK, AAB телефона и часов;
- проверку кодов версий и targetSdk;
- проверку, что в APK нет разрешения INTERNET;
- проверку виджетов.

Результаты и артефакты конкретного запуска смотрите во вкладке **Actions** репозитория.

## Конфиденциальность

Политика конфиденциальности находится в файле [PRIVACY_POLICY.md](PRIVACY_POLICY.md), действует с 23.11.2026. Приложение не собирает данные и не выходит в сеть. Напоминания и настройки хранятся только на устройстве, а импорт и экспорт идут через файлы, которые выбирает пользователь. Для Google Play политику нужно разместить по публичному адресу `https://niflaot.mychitas.app/peleshaon/privacy/`.
