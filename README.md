# Пеле Шаон Луах (Pele Shaon Luach)

Приложение для Android и Wear OS, связанное с еврейским календарём, временами дня и Шаббатом.

> Название продукта: **Пеле Шаон Луах**  
> Латинское написание: **Pele Shaon Luach**  
> Android application ID: `app.niflaot.peleshaon`

## Текущий статус

Проект находится на этапе подготовки к закрытому бета-тестированию в Google Play. Текущая версия в основной ветке Gradle: `1.0.0-beta3`, `versionCode=6`.

Это ещё не означает, что приложение опубликовано или готово к загрузке в Google Play. Для публикации потребуется подписанная production-сборка и завершение проверки материалов Play Console.

## Компоненты

- **Android-приложение** — основная версия для телефона.
- **Wear OS** — отдельная версия для совместимых часов.
- **Общий модуль `:core`** — общая логика расчётов для телефона и часов.

## Сборка для разработки

Проект использует Gradle и Android Gradle Plugin. Для локальной сборки откройте репозиторий в Android Studio и дождитесь синхронизации Gradle.

Основные модули:

- `:app` — Android-приложение.
- `:wear` — приложение для Wear OS.
- `:core` — общая логика.

Тестовые APK из GitHub Actions предназначены для проверки. Не используйте debug-ключ для production-публикации.

## Проверки

GitHub Actions выполняет проверки целостности исходников, тесты и сборку тестовых вариантов телефона и Wear OS. Состав проверок и результаты конкретного запуска смотрите во вкладке **Actions** репозитория.

## Конфиденциальность

Политика конфиденциальности находится в файле [PRIVACY_POLICY.md](PRIVACY_POLICY.md).

Политика сейчас является предварительным описанием текущей сборки. Перед публикацией в Google Play её необходимо сверить с окончательным кодом, фактическими разрешениями, используемыми SDK и настройками резервного копирования Android. Также необходимо указать действующий контакт разработчика и разместить политику по общедоступному HTTPS-адресу.
