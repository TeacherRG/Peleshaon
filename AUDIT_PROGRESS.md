# Аудит независимой Beta: фактический статус

Ветка `fixes/independent-beta`. Исходный коммит `8271045`.

## Исправления внесены в исходники (НО НЕ ПОДТВЕРЖДЕНЫ APK-тестами)

- B01: один расчёт времени Шма для часов и будильника.
- B02–B06: отмена snooze, правильный системный showIntent, защита сеанса звонка, уникальные PendingIntent, режим LIGHT_ONLY.
- B07–B12: закат в календаре/Wear OS, справочник городов, показ доступных времён, выбор Киева по Europe/Kyiv.
- B13–B15: платформа локали Android 13+, миграция языка, сохранение открытого экрана (ColorOS требует проверки).
- B16–B20: ближайшее событие на кнопке, окно виджета, тема при смене города, явно неизвестные полярные границы, новая Beta-версия.
- B23–B24: честная обработка разрешения уведомлений, гражданские годы в календаре.
- R01/R02/R04: без прямого запуска Activity из сервиса, перепланирование после обновления APK, безопасное чтение WakeMode.

## Открыто до приёмки

- B21: в публичной истории есть debug.keystore. Он используется только для debug Beta; безопасного release-ключа пока нет. Не выпускать Beta как доверенный публичный релиз.
- B22: при отсутствии точного разрешения остаётся неточный резервный будильник; нужен тест Android API/OEM и явный показ погрешности во всех местах UI.
- B13/B14: на реальном ColorOS необходимо проверить смену всех шести языков без ручного перезапуска, системный locale picker и уведомления.
- B04/B05: нужны сценарии двух одновременно звонящих будильников на реальном телефоне, с блокировкой, snooze и уведомлениями.
- R03: стоимость рендеринга bitmap в BroadcastReceiver пока не измерена.
- R05: разрешения точных будильников/политика Google Play требуют отдельного решения перед публикацией.
- R06/R07/R08: напоминание при более позднем восходе Луны, кашрут в Шабат и спорные галахические правила нельзя менять без утверждённой политики.
- R09/R10/R11/R12: полноценные UI/OEM-тесты, проверка фоновой локали, синхронизация Wear и крупное обновление KosherJava ещё не выполнены.

## Проверки

1. При каждом изменении: `python3 scripts/check_integrity.py`, `gradle :core:test`.
2. Сборка: `gradle :app:assembleDebug :wear:assembleDebug`.
3. Проверить APK package name = `app.mychitas.peleshaon.beta`, подпись, отсутствие INTERNET, отсутствие конфликта с оригиналом.
4. Сценарии на реальном Android и Wear OS — обязательны до заявления «все баги исправлены».

На форках GitHub Actions по умолчанию выключен. Чтобы CI запустился, владелец включает его на вкладке Actions.
